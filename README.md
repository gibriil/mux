# Mux  [![Go Reference](https://pkg.go.dev/badge/github.com/gibriil/mux.svg)](https://pkg.go.dev/github.com/gibriil/mux)
A Go Enum or general purpose multiplexer

The mux package is a way to build http server like multiplexers on enums or any comparable.

The mental model is similar to the Go stdlib net/http package where a NewMux is created then Handlers are attached to routes on the Mux.

##  Installation and Usage

The import path for the package is *github.com/gibriil/mux*.

To install it, run:

```bash
go get github.com/gibriil/mux@latest
```
